Enterprise ATS Vendor Evaluation & Strategy
Blizzard Entertainment

Led a specialized 3-month discovery initiative to evaluate Applicant Tracking Systems (ATS) and align platform capabilities with highly specific AAA gaming recruitment workflows.

The Challenge

The organization required a comprehensive technical and functional assessment of available ATS platforms within a strict timeframe prior to implementation handoff.

The Analytical Approach

Conducted deep-dive evaluations of multiple systems against internal requirements. Synthesized findings into a comparative matrix to identify optimal solutions.

The Outcome

Delivered a finalized top-three vendor recommendation and transition roadmap. The enterprise successfully adopted and deployed one of the recommended platforms.

Financial Process Optimization & Data Integrity Auditing
City of Albuquerque

Audited municipal Travel and Expense modules to resolve data abnormalities and streamline legacy public sector approval workflows.

The Challenge

Travel and Expense workflows suffered from inefficiencies, and proprietary PeopleSoft reporting logic was silently filtering out critical financial records from standard outputs.

The Analytical Approach

Reviewed module workflows for optimization opportunities. Executed side-by-side SQL comparisons between PeopleSoft's custom report function and Oracle SQL Developer to expose flawed forced logic.

The Outcome

Uncovered the root cause of missing data, corrected underlying SQL query structures for recurring reports, and provided actionable strategies to streamline the expense lifecycle.

Complex Cadence & Third-Party API Integration Rollout
AutoFi / Enterprise Auto Sector

Managed the interface architecture and operational alignment using Postman for API testing to integrate a major scheduling/cadence module into existing core operational software.

The Challenge

The Analytical Approach

The Outcome

Delivered integration milestone on schedule, established automated logging for API error handling, and reduced transaction processing times.
